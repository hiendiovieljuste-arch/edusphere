# Guide d’utilisation d’EduSphere

## 1. Bienvenue dans EduSphere

EduSphere est une plateforme simple et puissante pour gérer une école, une université, un centre de formation ou un établissement éducatif.

Tu n’as pas besoin d’être un expert pour l’utiliser. Tout est pensé pour être facile à comprendre.

---

## 2. Se connecter

1. Ouvre l’application dans le navigateur.
2. Clique sur la page de connexion.
3. Entre ton email et ton mot de passe.
4. Clique sur "Se connecter".

Exemples de comptes de test :

- Étudiant : student@edusphere.fr / password123
- Professeur : teacher@edusphere.fr / password123
- Admin : admin@edusphere.fr / password123

---

## 3. Ce que tu vois selon ton profil

### Si tu es étudiant
Tu vois :
- ton tableau de bord
- tes cours
- tes notes
- ta présence
- tes messages
- ton profil

### Si tu es professeur
Tu vois :
- tes cours
- tes étudiants
- les évaluations
- les devoirs
- les notifications
- le panneau d’administration utile

### Si tu es administrateur
Tu vois :
- établissements
- filières
- promotions
- classes
- étudiants
- enseignants
- paiements
- admissions
- rapports

---

## 4. Tableau de bord

Le tableau de bord est la page principale.

Tu y trouves :
- les statistiques
- les raccourcis rapides
- tes cours
- tes notifications
- ta progression

Clique sur les blocs pour ouvrir les pages correspondantes.

---

## 5. Gérer les cours

Dans la section cours :
1. Tu peux voir les cours disponibles.
2. Tu peux suivre un cours.
3. Tu peux vérifier ta progression.
4. Tu peux ouvrir une leçon ou une ressource.

Si tu es prof, tu peux aussi créer ou gérer des cours.

---

## 6. Voir tes notes

La page Notes montre :
- les matières
- les notes obtenues
- la moyenne
- l’évolution

Tu peux suivre rapidement ce qui va bien et ce qui doit être amélioré.

---

## 7. Suivre la présence

La page Présence affiche :
- ton taux de présence
- les heures validées
- les absences
- le calendrier de la semaine

C’est utile pour comprendre tes performances et rester à jour.

---

## 8. Messagerie

La messagerie sert à communiquer :
- avec les enseignants
- avec les camarades
- avec l’administration

Tu peux écrire un message et l’envoyer directement.

---

## 9. Profil et paramètres

Dans le profil :
- tu peux voir tes informations
- modifier ton nom ou bio
- gérer ton compte

Dans les paramètres :
- tu peux contrôler les préférences de l’application
- gérer les notifications
- ajuster l’affichage

---

## 10. Administration

Les responsables peuvent :
- gérer les établissements
- superviser les classes et promotions
- suivre les étudiants
- valider les candidatures
- suivre les paiements
- avoir des rapports globaux

C’est la partie “gestion complète” de l’application.

---

## 11. Pour un enfant de 10 ans : version ultra simple

Si tu es jeune, pense à EduSphere comme une boîte à outils d’école :

- Tableau de bord = ta page d’accueil
- Cours = tes matières
- Notes = tes résultats
- Présence = la liste de ceux qui sont là ou pas
- Messages = les messages de ton école
- Admin = le bureau qui gère tout

Tu n’as pas besoin de tout comprendre d’un coup. Clique, regarde, essaie.

---

## 12. Sécurité et confiance

EduSphere protège les comptes avec une connexion sécurisée.
Chaque utilisateur ne voit que les informations qui lui sont autorisées.

Cela évite qu’un élève voie les données d’un autre établissement ou d’un autre profil.

---

## 13. Astuces

- Utilise les raccourcis du tableau de bord pour aller vite.
- Consulte souvent les notifications.
- Vérifie tes notes et ta présence chaque semaine.
- Pour les admins, les rapports sont la meilleure source d’information.

---

## 14. Prochaine étape

Tu peux maintenant :
1. te connecter
2. tester chaque rôle
3. explorer les pages
4. vérifier les modules admin
5. préparer un déploiement pour le monde réel

Bon courage et bonne utilisation !
